# The agent skill

`SKILL.md` is generated by `renderSkill` in `src/skill.ts` from the view docs, the recipes in
`src/recipes.ts` and each source plugin's `skillNotes` (`packages/sources/src/*/index.ts`).
- It tells an agent what to do and what to read. Leave out how memindex works inside: no version
  numbers, scoring math, fidelity levels, embedding prefixes, chunker names or notes about older tools.
- A column or view that answers no user question carries `internal: true` in `VIEW_CONTRACT`. It stays
  in the store contract and is not rendered.
- One line per rule. Prefer a recipe plus one instruction over a paragraph.
- The guard tests in `tests/query.test.ts` reject build vocabulary and `1`/`0` for boolean params.
  Extend their lists instead of relaxing them.
- Skill text in `skill.ts` is a template literal with escaped backticks (`` \` ``). Search for the
  escaped form when editing it.
